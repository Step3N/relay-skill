# Relay — 让 Codex 记住项目，换个会话也能接着干

Relay 是一个让 Codex 自动记录工作、方便新会话接手的 Skill。

你只管正常聊天和开发，Relay 会让 Codex 在工作过程中，把值得保留的信息和最新进展整理成项目里的交接文档，不需要你反复提醒。

就像有一份随时更新的工作交接记录，换一个“新员工”，也能快速了解之前的工作，接着干活。

无论是突然断线、主动切换会话，还是过几天重新打开项目，都不用从头解释。

新会话输入 `$relay resume`，Codex 就会读取之前的记录，告诉你目前做到哪里、接下来准备做什么，等你确认后再继续。

所有记录都保存在项目本地，你也可以随时查看。

## 怎么用？

### 1. 安装一次

将下面这段话直接发给 Codex：

```text
请从 https://github.com/Step3N/relay-skill 安装 Relay，全程用中文汇报，并实际完成安装和可执行验证。

先获取仓库，阅读并遵循 README.md、skills/relay/SKILL.md 和 skills/relay/references/install.md，审查安装脚本后再执行。

确认实际安装目录，备份并保留全局 AGENTS.md 的原有规则，只安全合并 Relay 的托管块。保留用户修改，重复安装不产生重复配置；如有旧版 agent-continuity，按安装说明安全迁移。安装不在当前项目创建 .ai。

验证安装完整性、原规则保留和重复安装幂等。在隔离项目检查初始化是否保留已有信息，不修改当前项目。区分文件安装、客户端发现和真实行为验证，无法验证的部分明确说明。

最后报告实际安装路径、版本、备份位置、验证结果及新会话中的使用方式。请完成安装，不只告诉我步骤。
```

安装后打开新会话，让规则生效；选择器没有出现 `relay` 时再重启客户端。手动安装、更新和卸载见[安装说明](skills/relay/references/install.md)。

### 2. 正常工作，不用反复提醒

在项目里照常提出规划或开发任务。缺少交接文档时，Codex 会按需创建；已有文档时，会在重要工作开始前和取得阶段成果后更新。

记录默认使用简体中文，保存在 `.ai/PROJECT.md` 和 `.ai/HANDOFF.md`。你可以随时打开，了解项目要做什么、目前做到哪里、还有什么没完成。

只保留重要信息，不记录聊天流水账。普通问答、只读状态查询或仅安装 Skill 不会创建项目记忆。

### 3. 换个会话，先了解再继续

在同一项目的新会话里输入：

```text
$relay resume
```

Codex 会读取记录，并核对相关实际文件，说明当前进展、发现的差异和建议的下一步，然后**等待你明确确认**。

你看过汇报后回复“继续，按建议的下一步做”，才开始该范围的工作。确认前不会开发、修改记忆或运行测试。

## 三个调用

| 调用 | 用途 |
| --- | --- |
| `$relay resume` | 了解之前的工作和实际进展，确认后继续 |
| `$relay init` | 手动初始化或修复项目记忆，保留已有内容 |
| `$relay review` | 核对整理项目记忆，去重并标注过时信息 |

`init` 和 `review` 都不会开始开发。日常工作不需要每次调用 Skill，也不需要每个项目先手动执行 `init`。

仓库名是 **relay-skill**，安装后的 Skill 名是 **relay**；也可以通过客户端的 Skill 选择器调用。

## 记录的边界

Relay 保存的是重要信息和工作进展，不能恢复完整聊天记录。自动记录依赖 Codex 遵循规则，不保证实时保存或零信息丢失；突然中断时，最后一次记录之后的信息可能还没保存，需要结合实际文件补充。

记录会区分已确认要求、当前方案和未确认想法，避免把讨论过的方向当成已经决定的任务。新会话会先核对记录和实际项目，再等你确认后继续。

日常只依赖 Skill 和本地 Markdown 文档，无需后台服务、Hooks、MCP、数据库或额外模型 API。可选安装和初始化工具只使用 Python 3.10+ 标准库。

当前版本 **1.0.2**。兼容初版 Agent Continuity 的项目记忆，无需重建 `.ai`。安装器保留原有全局规则，重复安装和初始化不会覆盖已有信息；具体保护措施见[安装说明](skills/relay/references/install.md)。
