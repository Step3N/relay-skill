# Relay — 让 Codex 记住项目，换个会话也能接着干

Relay 是一个让 Codex 自动记录项目工作、方便新会话接手的 Skill。

你照常聊天、规划和开发，Relay 会让 Codex 把值得保留的信息和最新进展整理成项目里的交接文档，不需要你反复提醒。

突然断线、主动换会话，或过几天重新打开项目时，输入 `$relay resume`。Codex 会读取记录、核对实际文件，告诉你做到哪里、还有什么没完成，等你确认后再继续。

记录默认使用简体中文，保存在项目本地。你也可以随时查看，了解进展和开发方向。

## 安装与管理

把对应提示词直接发给 Codex 即可：

### 安装 Relay

```text
请从 https://github.com/Step3N/relay-skill 安装 Relay Skill，按照仓库说明完成全局配置和安装验证，保留我已有的配置。
```

### 更新 Relay

```text
请从 https://github.com/Step3N/relay-skill 更新 Relay 到最新版本，按照仓库说明安全升级，保留现有配置和项目记忆，完成后验证是否更新成功。
```

### 卸载 Relay

```text
请帮我完整卸载 Relay Skill，清理它添加的全局配置，但保留其他配置和所有项目记忆文件。删除前确认范围，卸载后验证结果。
```

安装、更新或卸载后，在新会话中确认生效；客户端没有刷新时再重启。供 Codex 执行操作的详细步骤见[安装与管理说明](skills/relay/references/install.md)。

## 日常怎么用

安装一次后，在项目里正常提出规划或开发任务即可。没有记录时，Codex 会按需创建；已有记录时，会在重要工作开始前、取得阶段成果后和结束前更新。

项目里有两份文档：`.ai/PROJECT.md` 保存长期目标和重要决定，`.ai/HANDOFF.md` 保存当前进度和未完成事项。普通问答、只读状态查询或仅安装 Skill 不会创建这些文件。

换到同一项目的新会话时，输入：

```text
$relay resume
```

看过接手报告后，再回复“继续，按建议的下一步做”。确认前，Codex 只查看和核对，不开发、不修改记录，也不运行测试。

| 调用 | 用途 |
| --- | --- |
| `$relay resume` | 了解之前的工作，确认后继续 |
| `$relay init` | 手动创建或修复项目记录，保留已有内容 |
| `$relay review` | 核对和整理项目记录 |

日常工作不用每次调用 Skill，也不用每个项目先手动执行 init。init 和 review 都不会开始开发。

仓库名是 **relay-skill**，调用名是 **relay**；也可以通过客户端的 Skill 选择器调用。

## 能记录到什么程度

Relay 保存重要信息和工作进展，不保存完整聊天记录。自动维护依赖 Codex 遵循规则，不保证实时保存或零信息丢失。突然中断后，最后一次保存之外的信息需要结合实际文件补充。

记录会区分已确认要求、当前方案和未确认想法。新会话会先核对记录，避免把讨论中的想法当作已经决定的开发任务。

日常只需要 Skill 和本地 Markdown 文件，不需要 Hooks、MCP、数据库、后台服务或额外模型 API。可选文件工具使用 Python 3.10+ 标准库。

当前源码版本 **1.0.2**。已有项目记录不会因更新而重建。
