# Relay · 项目接续

**记录项目的核心信息，帮助你掌握开发进度，让新会话快速接手。**

Relay 是一个面向中文使用场景的 Codex 全局 Skill。安装一次，正常在项目里让 AI 工作：没有项目记忆就按需创建，有记忆就持续维护。会话中断后，在同一项目的新会话里输入 `$relay resume`，先了解实际进度，确认后接着做。

## 为什么需要 Relay？

开发做到一半，会话突然断开，或反复重连后只能新开会话。代码还在，但上下文散了：

- **又要解释一遍**：项目要做什么、有哪些要求、为什么选这个方案。
- **不知道做到哪了**：哪些只是写完了，哪些已经验证，哪些还没完成。
- **新会话容易跑偏**：忘记限制，把讨论过的想法当成已经决定的方向。
- **用户难以掌握进度**：长对话里找目标、计划和当前状态，费时又容易遗漏。

Relay 将重要信息留在项目文件里。你可以直接阅读，新会话也能据此核验和接手。

## 怎么用？

### 1. 安装一次

将下面这段话直接发给 Codex：

```text
请从 https://github.com/Step3N/relay-skill 安装 Relay，全程用中文汇报，并实际完成安装和可执行验证。

先获取仓库，阅读 README.md、skills/relay/SKILL.md、skills/relay/references/install.md、全局规则模板和安装脚本，再执行审查过的安装器。

确认当前客户端实际支持的用户级 Skill 目录和 CODEX_HOME；保留全局 AGENTS.md 的原有规则，仅安全合并本 Skill 的托管块，写入前备份。检查 override、禁用配置和冲突，重复安装不得产生重复配置。若发现旧版 agent-continuity，按安装说明安全迁移，不保留两个同时生效的版本，不覆盖用户修改。

安装只涉及用户级 Skill 和全局托管规则，不在当前项目创建 .ai。验证格式、资源、引用、完整性、原规则保留和重复安装幂等；在隔离项目检查初始化保留已有信息。区分文件安装、客户端发现与真实行为验证，无法验证的部分明确说明。

最后给出实际安装路径、版本、备份位置、检查结果，以及新会话中的使用方式。请完成安装，不只告诉我步骤。
```

安装后打开新会话，让全局规则生效；选择器没有出现 `relay` 时再重启客户端。需要手动安装、更新或迁移时，见[安装说明](skills/relay/references/install.md)。

### 2. 正常让 AI 在项目里工作

例如：“实现这个项目的登录功能，先完成本地版本，不接第三方服务。”

不需要每次调用 Skill，也不需要给每个项目手动执行 `init`。实际项目任务开始时，Codex 按需创建两份记忆，在重要操作前和取得阶段成果后提炼更新：

| 文件 | 你能看到什么 |
| --- | --- |
| `.ai/PROJECT.md` | 项目背景、目标、已确认要求、约束、阶段规划、重要决策及原因 |
| `.ai/HANDOFF.md` | 当前工作、授权范围、已完成/未完成、已验证/待验证、阻塞和下一步 |

默认用简体中文记录。保留已有信息；只记关键内容，不记聊天流水账。普通问答、只读状态查询或仅安装 Skill 不会创建项目记忆。

### 3. 中断后，在同一项目的新会话里恢复

```text
$relay resume
```

Codex 会读取记忆，核对相关实际文件和 Git 状态，用中文说明目标、约束、规划、进度及差异，提出下一步，然后**等待你明确确认**。

确认前不会开发、改记忆或运行测试。你看过汇报后回复“继续，按建议的下一步做”，才开始该范围的工作。

有足够的已保存记忆时，你无需重新解释整个项目；缺失或过时的信息会明确指出。

## 三个调用

| 调用 | 用途 |
| --- | --- |
| `$relay resume` | 新会话只读核验、汇报，确认后继续 |
| `$relay init` | 手动初始化或修复记忆，保留已有内容，不开始开发 |
| `$relay review` | 核对整理记忆、去重和标注过时信息，不开始开发 |

客户端也可能通过 Skill 选择器调用。仓库名是 **relay-skill**，安装后的 Skill 名是 **relay**。Relay 意为“接力”：把项目状态交给下一段会话。

## 能保证什么，边界在哪？

- 安装器只管理自己的区域，保留原有全局规则；重复安装和初始化幂等。旧安装先核验、备份再迁移。
- 区分用户已确认要求、当前方案、探索想法和已验证事实，避免把 AI 推断当成你的决定。
- 恢复会核对实际项目，不把旧记忆里的“已完成”直接当成事实。
- 日常依靠 Skill 指令和 Markdown，**没有 Hooks、MCP、数据库、后台服务或额外模型 API**。可选安装/初始化工具只使用 Python 3.10+ 标准库。
- 自动维护依赖模型遵循规则，不是强制实时保存。突然断连时，最后一个检查点之后的信息可能未保存；Relay 不修复网络，也不能恢复未保存的聊天。

当前版本 **1.0.2**。兼容初版 Agent Continuity 的项目记忆，无需重建 `.ai`。

## 验证与仓库内容

```sh
python3 -m unittest discover -s tests -v
```

测试覆盖安装安全合并、幂等、旧版迁移、用户内容保留、失败回滚和记忆只读检查。GitHub Actions 在 Python 3.10/3.13 运行同一套测试。模型行为和桌面断连场景的验证范围见[验证记录](VERIFICATION.md)和[验收场景](tests/scenarios.md)。

核心文件在 `skills/relay/`：`SKILL.md`、中文全局规则与记忆模板、安装说明及标准库工具；`tests/` 为测试和行为场景。开发记忆、凭据及临时文件不进入发布包。
